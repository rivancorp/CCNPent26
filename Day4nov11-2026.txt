CONFIGURE REAL IP SLA: Service level agreement:

3 Parts: IP SLA, tracking and HSRP.
IP SLA (Internet Protocol Service Level Agreement)
measures network performance and connectivity
ICMP response time.
Packet loss.
Network latency.
Jitter.
TCP connectivity.

@R1: PrimaryInt
config t
ip sla 1 
  icmp-echo 8.8.8.8
  freq 30
  exit
ip  sla  schedule 1 life forever start-time now
track  1  ip sla 1
  delay down 6 up 3
  !Wait 6 seconds before declaring tracking DOWN
  !Wait 3 seconds before declaring tracking UP
  exit

end

config t
! Define an access control list (ACL) to match HTTP traffic
access-list 101 deny tcp any any eq 443
access-list 101 permit ip any any

! Create a class map to match the ACL
class-map match-all HTTPS-Traffic
  match access-group 101

! Create a policy map for CoPP
no policy-map Control-Plane-Policing

  class HTTPS-Traffic
    police 80000 1500 1500 conform-action transmit exceed-action drop violate-action drop
    exit

NetFlow is a Cisco technology that collects information 
about network traffic flows

-Source IP address.
-Destination IP address.
-IP protocol.
-Source port.
-Destination port.


configure terminal
interface gigabitEthernet1
 description NETFLOW-MONITORED-LINK
 
STEP1: Create a NetFlow Record

configure terminal
flow record NF-RECORD
 description COLLECT-IP-TRAFFIC
!
 match ipv4 source address
 match ipv4 destination address
 match ipv4 protocol
 match transport source-port
 match transport destination-port
!
 collect counter bytes long
 collect counter packets long
!
 collect timestamp absolute first
 collect timestamp absolute last
!
exit

STEP2: Create the NetFlow Exporter

config t
flow exporter NF-EXPORTER
 description SEND-FLOWS-TO-COLLECTOR
 destination 208.8.8.1
 source GigabitEthernet1
 transport udp 2055
 export-protocol netflow-v9
exit

STEP3: Create the Flow Monitor

config t
flow monitor NF-MONITOR
 description MONITOR-OUTBOUND-TRAFFIC
 record NF-RECORD
 exporter NF-EXPORTER
 !
 cache timeout active 60
 cache timeout inactive 15
!
exit

STEP3: Apply NetFlow to GigabitEthernet1

configure terminal
interface gigabitEthernet1
 ip flow monitor NF-MONITOR output
exit
end
